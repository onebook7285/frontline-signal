# 美術方向（Art Direction）

- 版本：v0.2｜2026-11-21
- 文件角色：視覺支柱、可讀性、MVP 素材清單與素材管線的單一來源。
- 狀態：方向候選；尚未有正式美術。灰盒以幾何形狀與圖標為主，不阻塞 M0／M1。
- 相關：[`content-policy.md`](content-policy.md)、[`game-design.md`](game-design.md)、[`ASSETS.md`](../ASSETS.md)

## 1. 視覺支柱

1. **輪廓優先**：在 50% 縮放、灰階、色盲模擬下，仍能從輪廓分辨兵種與陣營。
2. **架空時代感**：二戰至戰後的工業氣質，但不是歷史照片或真實裝備複刻。
3. **指令部視角**：俯視、戰術地圖感、乾淨的資訊層；不是第一人稱或電影式運鏡。
4. **可讀的混亂**：爆炸、煙塵與單位擁擠時，仍看得懂誰在哪、什麼正在發生。
5. **少即是多**：MVP 用有限素材與色塊建立辨識，不靠大量裝飾。

## 2. 陣營識別

敵我不能只靠顏色。建議同時使用：

| 通道 | A 陣營 | B 陣營 |
|---|---|---|
| 主色 | 冷色（例：青灰） | 暖色（例：土黃） |
| 形狀語言 | 方正、厚重、直角 | 圓滑、低矮、斜角 |
| 單位標記 | 實心三角／條紋 | 空心圓／點狀 |
| 基地建築 | 平頂、模組化 | 斜頂、外露結構 |
| UI 標記 | 實線框 | 虛線框 |

- 實際色票待定；先用高對比、低飽和，避免紅綠色盲問題。
- 顏色只是輔助；灰階測試必須仍可辨識。
- 不採用真實國旗、軍徽、黨徽或歷史單位標記。

## 3. 視角與鏡頭

- 俯視或略帶 3/4 的戰術視角；MVP 暫定固定全圖，不旋轉。
- 單位以「圖標＋剪影」呈現，比例可以誇張，優先可讀性。
- 地面用格線與色塊分層；路線、前哨、總部要有清楚的視覺層級。
- 不做第一人稱、過肩鏡頭、鏡頭晃動或電影式過場。

## 4. MVP 素材清單

| 類別 | 數量 | 備註 |
|---|---|---|
| 地面 tile | 3–5 種 | 草地、泥地、道路、據點底盤；可先用色塊 |
| 總部 | 每陣營 1 | 大型、輪廓清楚、有 HP 條 |
| 前哨 | 每陣營 2（每路 1） | 中型、與總部區分；損壞狀態 |
| 固定砲塔 | 1–2 | 與單位輪廓區分 |
| 步兵 | 1 | 小隊圖標，不是單人像素 |
| 坦克 | 1 | 中型坦克剪影 |
| 火砲 | 1 | 長管、低矮 |
| 偵察車 | 1 | 輕、快、圓滑 |
| 投射物／特效 | 3–5 | 槍火、砲彈、爆炸、煙塵；抽象 |
| UI 圖標 | 10–15 | 補給、生產、研究、路線、暫停、速度、設定 |
| 字型 | 1–2 | 可商用／開源；需支援繁中 |

- 先做灰盒 placeholder：幾何形狀＋文字標籤。沒有正式美術也能測規則。
- 每個素材要有：ID、尺寸、錨點、圖層、是否可翻轉、授權欄位。
- 動畫帧數先少；用位移、縮放、閃爍與粒子表達，不追求逐帧動畫。

## 5. 可讀性檢查

- **灰階測試**：關掉顏色，仍能分辨敵我與兵種。
- **色盲模擬**：至少檢查 protanopia、deuteranopia、tritanopia。
- **50% 縮放**：在 iPad 與小筆電上，單位仍可點選與辨識。
- **擁擠測試**：全場 60 單位＋特效時，選取框、HP 條、路線標記不互相遮擋。
- **動態測試**：移動中的單位與投射物不閃爍、不抖動。
- **背景測試**：不同地形與煙塵下，UI 與單位仍有對比。
- **觸控測試**：主要按鈕與單位選取面積足夠；不要求精準點擊。

## 6. 素材管線

1. 先在 issue 定義素材需求：用途、尺寸、圖層、狀態、授權。
2. 用 placeholder 先接進遊戲，確認比例與可讀性。
3. 正式素材進來前，先在 PR 附灰階與實機截圖。
4. 匯出格式與尺寸依 atlas／載入預算；避免單張大圖。
5. 更新 [`ASSETS.md`](../ASSETS.md)：路徑、作者、來源、授權、修改、署名。
6. 在 `art-direction.md` 記錄視覺決策；在 `content-policy.md` 檢查符號與暴力尺度。

### 6.1 命名

- 單位：`unit.<type>.<faction>`，例如 `unit.tank.a`、`unit.infantry.b`。
- 建築：`building.hq.a`、`building.outpost.b`、`building.tower.neutral`。
- 特效：`fx.explosion.small`、`fx.muzzle.tank`。
- UI：`ui.icon.supply`、`ui.icon.research`。
- 狀態：`unit.tank.a.damaged`、`building.outpost.b.destroyed`。

## 7. 音訊

- MVP 暫定無音訊；若加入，以最小 SFX 為主：下單、擊毀、前哨、總部、勝利／失敗。
- 音樂先不做；避免授權與載入預算問題。
- 重要音效要有視覺替代；提供靜音與音量。
- 音訊素材也要記授權，不能拿來路不明的音效包。
